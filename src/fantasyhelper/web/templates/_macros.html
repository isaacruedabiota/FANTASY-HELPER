{# Piezas reutilizables. La tarjeta de jugador es la unidad de toda la web: en un movil una tabla de doce columnas no se lee, y dos lineas de texto si. Las macros reciben los datos sueltos y montan el HTML ellas. Componer cadenas con HTML dentro y pasarlas como argumento no funciona: Jinja las escapa y en pantalla sale el `` escrito tal cual, que es justo lo que paso la primera vez que se miro la pagina. #} {% macro euros(valor, cero=false, corto=true) %} {%- if valor is none or (valor == 0 and not cero) -%} – {%- else -%} {# El signo va escrito, no solo en el color: rojo y verde se confunden con deuteranopia, asi que el color refuerza pero nunca informa el solo. #} {{- '+' if valor > 0 -}}{{ valor|moneyk if corto else valor|money }} {%- endif -%} {% endmacro %} {# Foto del jugador con el escudo de su equipo encima. Las dos imagenes salen del CDN publico de Mister, que las sirve por id. Se cargan desde el navegador y no a traves de la Raspberry a proposito: son ficheros estaticos que el navegador cachea, y hacerlas pasar por el servidor solo anadiria latencia y trabajo a una maquina que ya va justa. `loading=lazy` porque el mercado son setenta jugadores y no se ven de golpe. `onerror` esconde la imagen en vez de dejar el icono de rota: a un fichaje recien llegado puede que el CDN aun no le tenga foto. #} {% macro foto(fila) %} {%- set jugador = fotos_jugador.get(fila.id) -%} {%- set escudo = fotos_equipo.get(fila.team_id) -%} {%- if jugador or escudo -%} {%- if jugador -%} {%- endif -%} {%- if escudo -%} {%- endif -%} {%- endif -%} {% endmacro %} {# Escudo suelto, para las listas de rivales del calendario. Sin `title` propio: dentro del calendario el rotulo lo lleva el recuadro que lo envuelve, y un `title` vacio en la imagen tapa el del padre. #} {% macro escudo(team_id) %} {%- set id = fotos_equipo.get(team_id) -%} {%- if id -%} {%- endif -%} {% endmacro %} {# El rival, en mayusculas y sin arroba. La sede va en una etiqueta aparte -L de local, V de visitante- en vez de en un simbolo pegado al nombre. Un nombre de equipo es un nombre propio y se lee mejor limpio; y donde no se sepa la sede, que es media rejilla del calendario, no aparece nada en vez de dar por hecho que juega fuera. #} {% macro rival(fila) %} {%- if fila.opponent -%} {{ fila.opponent|upper }} {%- if fila.is_home is not none %}{{ 'L' if fila.is_home else 'V' }}{% endif -%} {%- else -%}–{%- endif -%} {% endmacro %} {# Segunda linea: de donde sale el jugador y en que estado esta. #} {% macro contexto(fila) %} {{ (fila.team or '?')|upper }} · {{ rival(fila) }} {%- if fila.probability is not none %} · {{ (fila.probability * 100)|round|int }}%{% endif -%} {# El estado solo cuando no hay `motivo`: en las pantallas que lo calculan, ese ya dice lo mismo y mejor, y repetirlo llenaba la linea de ruido. #} {%- if fila.status and fila.status != 'ok' and not fila.motivo %} {{ fila.status|replace('_', ' ') }} {%- endif -%} {% endmacro %} {# Los rivales de las proximas jornadas, en escudos. Sirve para lo que pedia el ojo y no la tabla: ver de un vistazo si a quien vas a fichar le viene un calendario amable. El color del borde dice si la jornada suma o resta, y el `title` lo escribe con palabras para quien no distinga los tonos. #} {% macro calendario(fila, nota='') %} {%- if fila.proximas or nota -%} {%- for j in fila.proximas -%} {{- escudo(j.opponent_id) -}} {%- endfor -%} {%- if nota %}{{ nota }}{% endif -%} {%- endif -%} {% endmacro %} {# Tarjeta de jugador. `tipo` decide que cifra manda a la derecha: rendimiento euros por semana (la sintesis) ventaja lo que se aparta de su tramo de precio semanas cuanto tarda un rival en amortizar su clausula puntos lo que se espera de el ESTA jornada, que es lo unico que cuenta al alinear: la revalorizacion la cobras igual desde el banquillo `coste` es el numero pequeno de la esquina: precio, clausula o lo que toque. #} {% macro tarjeta(fila, tipo='rendimiento', coste='market_value', sufijo='', vendedor=false) %} {{ foto(fila) }} {{ fila.position or '?' }}{{ fila.name }} {%- if tipo == 'semanas' -%} {{ fila.semanas_amortizacion|round|int }}sem {%- elif tipo == 'ventaja' -%} {{ euros(fila.euros_ventaja) }} {%- elif tipo == 'puntos' -%} {{ fila.puntos_jornada|points }}pts {%- else -%} {{ euros(fila.rendimiento_semanal, cero=true) }}/sem {%- endif -%} {# El vendedor va DELANTE y no al final. La linea se recorta con puntos suspensivos cuando no cabe, y puesto al final se comia justo lo que se habia venido a mirar: si lo pone Mister -y entonces se compra al momento- o lo pone un participante, que es una puja. #} {%- if vendedor -%} {{- 'MISTER' if not fila.seller else fila.seller -}} {%- endif -%} {# Por que no juega, delante de todo: en el banquillo esa es la unica pregunta, y al final de la linea se lo comian los puntos suspensivos. #} {%- if fila.motivo -%}{{ fila.motivo }}{%- endif -%} {{ contexto(fila) }} {{- fila[coste]|moneyk }} €{{ sufijo -}} {%- if tipo == 'rendimiento' and fila.xpts is not none %} · {{ fila.xpts|points }} pts{% endif -%} {{ calendario(fila) }} {% endmacro %} {# Un hueco del campo: la foto, el nombre y lo que se espera de el. Mucho mas estrecho que una tarjeta a proposito. Un once son once nombres y la forma en que se colocan ES el dato: puestos en lista se pierde de vista que hay cuatro defensas y dos delanteros, que es justo lo que hay que decidir. Los detalles de cada uno estan a un clic, en su ficha. #} {% macro hueco(fila) %} {{ foto(fila) }} {{ fila.name }} {{ fila.puntos_jornada|points }} {%- if fila.motivo %}{{ fila.motivo }}{% endif -%} {% endmacro %} {# Un fichaje que mejoraria el once. La cifra que manda no es lo que rinde el jugador sino lo que SUMA al once: fichar un delantero de seis puntos no aporta nada si los tres que tienes ya hacen siete. #} {% macro fichaje(datos) %} {%- set cambio = [] -%} {%- if datos.desplaza -%} {%- set _ = cambio.append('por ' ~ datos.desplaza|map(attribute='name')|join(' y ')) -%} {%- endif -%} {%- if datos.cambia_formacion -%} {%- set _ = cambio.append('en ' ~ datos.formacion) -%} {%- endif -%} {{ foto(datos.jugador) }} {{ datos.jugador.position or '?' }}{{ datos.jugador.name }} {# Con la plantilla corta la cifra que importa no son los puntos -no hay once al que sumarlos- sino que tapa uno de los huecos que impiden alinear. #} {%- if datos.gana > 0 -%}+{{ datos.gana|points }}pts {%- else -%}+{{ datos.tapa }}hueco{%- endif -%} {{ datos.tipo|upper }} {{ contexto(datos.jugador) }} {{- datos.coste|moneyk }} € {%- if datos.coste_por_punto %} · {{ datos.coste_por_punto|moneyk }} €/pt{% endif -%} {{ calendario(datos.jugador, cambio|join(' · ')) }} {% endmacro %} {% macro lista(filas, tipo='rendimiento', coste='market_value', vacio='Nada que mostrar.', sufijo='', vendedor=false) %} {% if filas %}
