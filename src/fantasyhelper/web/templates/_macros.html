{# Piezas reutilizables. La tarjeta de jugador es la unidad de toda la web: en un movil una tabla de doce columnas no se lee, y dos lineas de texto si. Las macros reciben los datos sueltos y montan el HTML ellas. Componer cadenas con HTML dentro y pasarlas como argumento no funciona: Jinja las escapa y en pantalla sale el `` escrito tal cual, que es justo lo que paso la primera vez que se miro la pagina. #} {% macro euros(valor, cero=false, corto=true) %} {%- if valor is none or (valor == 0 and not cero) -%} – {%- else -%} {# El signo va escrito, no solo en el color: rojo y verde se confunden con deuteranopia, asi que el color refuerza pero nunca informa el solo. #} {{- '+' if valor > 0 -}}{{ valor|moneyk if corto else valor|money }} {%- endif -%} {% endmacro %} {# Foto del jugador con el escudo de su equipo encima. Sin `title` propio: dentro del calendario el rotulo lo lleva el recuadro que lo envuelve, y un `title` vacio en la imagen tapa el del padre. #} {% macro escudo(team_id) %} {%- set id = fotos_equipo.get(team_id) -%} {%- if id -%} {%- endif -%} {% endmacro %} {# El rival, en mayusculas y sin arroba. Un nombre de equipo es un nombre propio y se lee mejor limpio; y donde no se sepa la sede, que es media rejilla del calendario, no aparece nada en vez de dar por hecho que juega fuera. #} {% macro rival(fila) %} {%- if fila.opponent -%} {{ fila.opponent|upper }} {%- if fila.is_home is not none %}{{ 'L' if fila.is_home else 'V' }}{% endif -%} {%- else -%}–{%- endif -%} {% endmacro %} {# Segunda linea: de donde sale el jugador y en que estado esta. #} {% macro contexto(fila) %} {{ (fila.team or '?')|upper }} · {{ rival(fila) }} {%- if fila.probability is not none %} · {{ (fila.probability * 100)|round|int }}%{% endif -%} {%- if fila.status and fila.status != 'ok' %} {{ fila.status|replace('_', ' ') }} {%- endif -%} {% endmacro %} {# Los rivales de las proximas jornadas, en escudos. Sirve para lo que pedia el ojo y no la tabla: ver de un vistazo si a quien vas a fichar le viene un calendario amable. El color del borde dice si la jornada suma o resta, y el `title` lo escribe con palabras para quien no distinga los tonos. #} {% macro calendario(fila) %} {%- if fila.proximas -%} {%- for j in fila.proximas -%} {{- escudo(j.opponent_id) -}} {%- endfor -%} {%- endif -%} {% endmacro %} {# Tarjeta de jugador. `tipo` decide que cifra manda a la derecha: rendimiento euros por semana (la sintesis) ventaja lo que se aparta de su tramo de precio semanas cuanto tarda un rival en amortizar su clausula `coste` es el numero pequeno de la esquina: precio, clausula o lo que toque. #} {% macro tarjeta(fila, tipo='rendimiento', coste='market_value', sufijo='', vendedor=false) %} {{ foto(fila) }} {{ fila.position or '?' }}{{ fila.name }} {%- if tipo == 'semanas' -%} {{ fila.semanas_amortizacion|round|int }}sem {%- elif tipo == 'ventaja' -%} {{ euros(fila.euros_ventaja) }} {%- else -%} {{ euros(fila.rendimiento_semanal, cero=true) }}/sem {%- endif -%} {# El vendedor va DELANTE y no al final.
